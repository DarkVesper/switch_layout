# switch_layout

Консольная утилита для текста, набранного в неправильной раскладке.
Читает буфер обмена, меняет раскладку RU ↔ EN и записывает результат обратно.
Например, `ghbdtn` превращается в `привет`, а `Привет` — в `Ghbdtn`.

## Установка

Нужен Python 3.10 или новее. Команды для PowerShell из папки проекта:

```powershell
py -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -e ".[dev]"
```

Если активация окружения заблокирована, можно запускать Python напрямую:

```powershell
.\.venv\Scripts\python.exe -m pip install -e ".[dev]"
.\.venv\Scripts\switch_layout.exe --help
```

На Linux для доступа к буферу обмена может понадобиться `xclip` или `xsel`.

## Использование

Скопируйте текст в буфер и выполните:

```powershell
switch_layout convert
```

Результат появится в консоли и в буфере обмена. Регистр сохраняется:
`Ghbdtn!` → `Привет!`, `Rfr ltkf` → `Как дела`.

Направление определяется по тому, каких букв больше — русских или английских.
Пустой текст, текст без этих букв и равное количество букв двух алфавитов
считаются ошибкой.

Статистика записанных конвертаций:

```powershell
switch_layout stats
switch_layout stats --view abs
switch_layout stats --view rel
```

По умолчанию выводятся количество и процент для каждого направления,
а также длина самого длинного текста. Например:

```text
en-ru: 8 (66.7%)
ru-en: 4 (33.3%)
Самый длинный текст: 57 символов
```

`--view abs` оставляет только количество, `--view rel` — проценты.
Максимальная длина показывается в обоих случаях. Если записей нет, выводятся нули.

Также можно запускать команды через `python switch_layout.py convert`
и `python switch_layout.py stats`.

## Данные и ошибки

При первом запуске `convert` или `stats` создаётся SQLite-база `stats.db`
в текущей папке. В ней хранятся направление конвертации и длина исходного текста.
Сам текст в базу не попадает. События и ошибки записываются в `app.log`.
Оба файла исключены из Git.

Ошибки буфера обмена и чтения статистики приводят к ненулевому коду завершения.
Если текст уже попал в буфер, а статистику записать не удалось, команда выводит
результат и предупреждение с кодом 0. Повторять конвертацию в этом случае не нужно.

```powershell
python -m pytest -v

ruff format --check .
```

Тесты используют временные базы и подменяют буфер обмена.
Для форматирования кода: `ruff format .`.
